# EcoRunner

A 2D eco-themed game developed using Python and Pygame.

## 🌱 Features

- 🎮 2D gameplay
- 🌍 Eco-themed game environment
- 🧍 Player movement and controls
- ⚠️ Avoid environmental hazards
- 🗑️ Collect items throughout the game
- ⏱️ Timed gameplay
- 🏆 High-score and leaderboard system
- 🎚️ Multiple difficulty levels
- 🖥️ Custom game menu and interface

## 🛠️ Technologies

- Python
- Pygame

## 🎓 College Project

This project was developed as part of my Level 3 BTEC Computing studies.

The project achieved a **Distinction**.

## 🚀 Running the Project

### Requirements

- Python 3
- Pygame

### Installation

Clone the repository and install the required dependency:

```bash
git clone https://github.com/anec-p06/EcoRunner.git
cd EcoRunner
pip install pygame
```
### To run game

Open terminal and enter

```bash
python3 main.py
```
